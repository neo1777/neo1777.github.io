# neo1777 — portfolio GitHub Pages

Portfolio statico e curriculum in `cv/`. Il sito principale con report e articoli
è [neo1777.netlify.app](https://neo1777.netlify.app/); questa pagina GitHub Pages
resta una presentazione completa con progetti, contributi, scritti e link al CV.

## Struttura

- `index.html` — portfolio, profilo tecnico e schede dei progetti.
- `cv/index.html` — curriculum, con nome anagrafico e contatti richiesti per la
  candidatura.
- `sitemap.xml` e `robots.txt` — indicizzazione del portfolio e del CV.

## Aggiornare il portfolio

1. Modificare `index.html` mantenendo l’identità `neo1777` e i link alle prove
   pubbliche.
2. Aggiornare gli stati di progetto quando demo, repository o release cambiano.
3. Distinguere esplicitamente codice, demo, concept/mockup e lavori in corso.
4. Verificare i link e aprire `index.html` a larghezza desktop e mobile.
5. Aggiornare il sito principale su Netlify con lo stesso profilo e gli stessi
   riferimenti essenziali.

La direzione visiva segue N1777: inchiostro freddo, testo caldo, accento ottone,
Fraunces per i titoli, Archivo per l’interfaccia e JetBrains Mono per i dati.
Le pagine non ripetono il nome anagrafico fuori dal CV e dai contesti legali.
