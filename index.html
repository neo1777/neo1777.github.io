vps1777 — gateway self-hosted per server MCP

PythonDockerOAuth 2.1in produzioneMIT

Espone i miei server MCP a client LLM dietro un unico URL HTTPS: gateway OAuth 2.1 con Dynamic Client Registration e PKCE, reverse proxy, architettura a plugin, installer grafico cross-OS in Python puro. CI su GHCR con immagini firmate cosign verificate fail-closed, SBOM, digest immutabili e rollback automatico su health-gate. Dietro girano tre miei server MCP: retrieval full-text FTS5, uno che copre la superficie di NotebookLM con 38 tool, e OCR in container interno.

La parte di cui vado più fiero non è una funzione, è un vincolo: un ledger delle feature verificato in CI nei due sensi, e un gate su SECURITY.md che fa fallire la build se un rilievo dichiarato chiuso perde la sua evidenza nel codice. Nasce da una mia dichiarazione di sicurezza invecchiata in silenzio.
