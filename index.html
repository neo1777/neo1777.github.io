Gateway self-hosted per server MCP

PythonDocker ComposeOAuth 2.1MIT

Riunisce server MCP e bot dietro un gateway con accesso OAuth 2.1, reverse proxy, pannello amministrativo, Mini App Telegram e un installer grafico per Windows, macOS e Linux. I backend sono separati dal gateway su una rete Docker interna; i rilasci prevedono firma, SBOM, digest verificati e rollback su health gate.

Tra i servizi collegabili ci sono un archivio con ricerca FTS5 e modalità ibrida, strumenti MCP per NotebookLM e un servizio OCR. Il repository documenta anche plugin, backup, ingress e modello di sicurezza.

Lista contributor ↗

La mia prima issue pubblica sul progetto, #919, analizzava come i super-hub potessero unire comunità di codice poco coese e proponeva opzioni per controllare il clustering. Una segnalazione successiva (#934) ha isolato un errore del comando `cluster-only`; la prima proposta di fix è PR #942.

Due contributi successivi, #3933 e #3934, hanno portato fix per il clustering con `--exclude-hubs` e per il bonus di sorpresa tra repository e directory. Le PR sono state chiuse senza merge formale, ma i due commit sono presenti nel repository upstream e nella release v0.9.73. GitHub attribuisce due contributi al mio profilo.
